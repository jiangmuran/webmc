webmc asset provenance
======================

The PNG textures in this directory tree were extracted from the "Reimagined"
texture pack (originally titled "Minecraft Reimagined") authored by Reijvi.
Reijvi executed an authorization letter on 2026-04-23 granting jmr a full,
irrevocable, worldwide, royalty-free, and perpetual right to use, modify,
distribute, publish, sublicense, and otherwise exploit the entirety of that
work, and waiving all copyright, moral, and attribution rights.

The authorization letter is preserved at:
  外部授权开源材质包/§aReimagined§0_§8[v1.62.2]§0/AUTHORIZATION.txt

Under the terms of that grant, the PNG files under this directory tree are
redistributed by the webmc project as part of the webmc source tree, which is
itself licensed under the GNU Affero General Public License v3.0 or later.

What is NOT included here:
  - assets/minecraft/ directory structure (Mojang's resource-pack schema).
  - pack.mcmeta, overlay version directories, respackopts.json5.
  - models/, blockstates/, shaders/, font/, lang/, particles/ JSON files
    and the shader source (.fsh/.vsh) files — these encode Mojang's asset
    schema rather than Reijvi's artwork, and webmc uses its own registry
    format.
  - Sounds, music, or entity model definitions from any source.
