What it is

webmc is a Minecraft-Java-Edition-equivalent voxel sandbox running entirely in modern browsers — desktop and mobile, single-player and peer-based multiplayer. It is a clean-room reimplementation: no decompiled Mojang source code, no Mojang textures or audio shipped in this repo. Open-source under AGPL-3.0.

What's in the build

620+ blocks

Wool, terracotta, concrete, glass, glazed terracotta, copper oxidation chain, ores, deepslate, sculk, amethyst, mushrooms, prismarine, all stone variants.

220+ items

Tools, armor (incl. elytra, turtle shell), 14 potions + splash, 28 spawn eggs, 36 boat/sign variants, food, dyes, smithing templates, bottle o' enchanting.

71 mob defs

Pig/cow/sheep/wolf/horse/cat/parrot/wither/dragon/warden/breeze/sniffer/armadillo/villager + biome-aware spawn tables.

180+ chat commands

/tp /home /tame /breed /craft /village /tower /sphere /portal /firework /army /perf /test — type /help.

Mechanics shipped

Farming + bone-meal, mob breeding + babies, elytra glide + firework boost, mace smash, trident riptide, splash potions, sponge soak, fishing, axe stripping, hoe tilling.

Performance

Mesh-budget cap, movement-biased chunk priority, idempotent registries, palette+bitpacked storage. Optimized for low-end laptops/phones.

Quick start (developers)

git clone https://github.com/jiangmuran/webmc.git
cd webmc
npm install
npm run dev          # http://localhost:5173
npm run typecheck    # strict TS
npm run test         # 11500+ unit tests
npm run lint         # eslint
npm run build        # static dist/

Development pipeline (流水线)

  • 1. main — protected; only via PR; auto-deploys to GitHub Pages.
  • 2. dev — integration branch; CI gate before merging to main.
  • 3. feature/* — short-lived branches per feature; PR into dev.
  • 4. CI — typecheck → lint → format:check → unit tests (11593 vitest) → playwright e2e.
  • 5. Auto-merge — daily PR opens dev → main when CI green.
  • 6. Pages — every push to main builds + publishes https://jiangmuran.github.io/webmc/.

Clean-room IP

No decompiled Minecraft source code is ever read. No Mojang textures or audio are committed to this repository. Behavioral references come exclusively from minecraft.wiki + the user's natural-language descriptions. See the README + AGENT_CHARTER.md for the full policy.
