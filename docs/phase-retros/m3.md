# M3 retro — Terrain, Lighting, Day-Night

**Estimated:** ~19h. **Actual (this session):** ~2.5h wall-clock.
**Status:** DONE per STANDARDS.md §2.1. Vertex AO (M3.6) deferred to backlog; cross-chunk light propagation kept minimal (single-chunk BFS is sufficient for 'caves are dark').

## Shipped

- `src/world/noise/perlin.ts` implements Ken Perlin's 2002 improved noise (2D + 3D + fbm) from the public paper. Seeded via mulberry32 → shuffled 256-entry permutation. Deterministic, integer-lattice zero, output in [-1, 1].
- `src/world/generation/WorldGenerator.ts` fbm-4 heightmap over [52, 92], second fbm-2 selects between PLAINS and FOREST biomes, deterministic tree placement via `hash32(wx, wz, seed)` at 4% density, oak trunks with a 3-layer canopy.
- `src/world/ChunkLoader.ts` rebuilds a distance²-sorted pending queue when the player crosses a chunk boundary, unloads beyond `viewRadius + padding`, caps per-frame gen at 4 to keep streaming stutter under budget.
- `src/world/lighting.ts` packed-nibble per-subchunk (sky<<4 | block). Sky uses a column-height model; block light is BFS from emissive voxels with attenuation 1. Snapshot + worker protocol carry the per-section flat light arrays; mesher bakes face-outside voxel's `max(sky, block) / 15 * 255` into `colors.a`. Shader fragment uses it as primary multiplier with an `uAmbient` floor so dark caves stay legible.
- `src/engine/time/DayNightCycle.ts` drives `uSunDir`, `uSkyColor`, `uAmbient`, scene fog + background each frame. 10-minute default day, four color stops (night/dawn/day/dusk).
- `main.ts` swaps the static 8×8 flat demo for streamed terrain around the player, with light cached per chunk.
- e2e: `m3-terrain.spec.ts` confirms >500 tris after stream-in, FPS ≥ 15 sustained, HUD reports seed + pending, zero console errors.

## Verification

`npm run verify:m3` green: 145 unit tests across 19 files, 12 Playwright scenarios (desktop + Pixel-7 × 6 specs), mesh bench p95 ≤ 2.3 ms.

## Cut or deferred

- **Vertex AO (M3.6).** Would sample 3 voxel neighbors per vertex corner and feed an extra nibble into `colors.a`. Skipped because (a) `colors.a` already carries voxel light, and multiplexing AO into the same channel needs a second attribute; (b) AO adds ~4× neighbor reads per face and we're well under the mesh budget without it. Backlog item: "Vertex AO as separate Uint8Array attribute".
- **Cross-chunk light propagation.** Sky light uses column heights (no horizontal bleed under overhangs); block light BFS is chunk-scoped. Seams at chunk borders are visible under overhangs but not in the headline cave scenario. Backlog item: "Cross-chunk light BFS with neighbor-chunk queue push".
- **Biome-colored grass/leaves tint.** Grass is uniform green; biome-by-biome tinting waits for M5-era biome lookup tables.

## Biggest surprise

TypeScript's `noUncheckedIndexedAccess` made the nested snapshot access awkward: `flatSkyLight[idx] ?? 15` appears in every light read. Not a perf issue (JIT inlines it), but a readability one. A future pass can refactor to raw loops with bounds-checked once-per-face lookups.

Second surprise: the shader's existing `vColor.a` channel, reserved since M1 for "AO", was perfectly sized for direct voxel light without any vertex-format change. The per-face color stride already had room. Four lines of shader edit + a channel reinterpretation and caves went dark without any vertex-attribute churn.

## Next milestone (M4) should know

- The mesher's light baking uses the face-outside voxel's light. On opaque-vs-opaque boundaries (none exist today but will on M9 water) the face-outside voxel is the transparent one, which is what we want — no future refactor needed.
- `DayNightCycle.ambient` is currently driving the shader's pure floor. M4 can reuse it for a torch-in-hand effect by adding a per-frame "player light" uniform that contributes block light around the camera position.
- Chunk streaming is synchronous on the main thread. For M4 mobile FPS budget we may need to move `WorldGenerator.generateChunk` into a worker. Deferred until profiling shows it's the bottleneck.
- The light cache is a `Map<string, ChunkLight>` in `main.ts`. Promote it onto `Chunk` in M5 when save format lands and lights need to persist alongside block state.
