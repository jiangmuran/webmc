## Biggest surprise

The user has a local `/mc-ref/` directory with decompiled MC source + Mojang textures and twice asked for it to be used as a reference. Holding the clean-room line required (a) declining the reference use, (b) adding `mc-ref/` to gitignore, (c) hardening charter/plan/STANDARDS/memory to flag it as quarantined for all future sessions. Clean-room policy must be defended in the face of well-meaning user pressure, not just in docs.

A secondary surprise: the user's shell has a local HTTP proxy (127.0.0.1:7897) that hijacks localhost requests. Playwright's webServer health-check and Chromium's page load both went through it and got 502. Fix: `no_proxy` set inline in the `test:e2e` npm script + `--proxy-server=direct://` in Chromium launch args.
