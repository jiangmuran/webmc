# M11 — Extended Mobs (Retrospective)

## Shipped

- **Mob roster 3 → 10**: pig, cow, sheep, chicken (passive); wolf (neutral); zombie, skeleton, creeper, spider, enderman (hostile).
- **Behavior category** replaces the binary `hostile` bool — `passive | hostile | neutral | creeper | enderman` drives `isAggroTarget` and lets different kinds share the same chase loop while overriding one dimension (fuse, teleport, jump).
- **Creeper fuse** primes at 2.5 m for 1.5 s and detonates for 12 damage + self-removal.
- **Neutral provocation** — wolves + endermen only aggro after `damage()`; the flag persists until death. Covered by a test that pokes a wolf and watches it reverse direction.
- **Spider jump** — any mob with `jumpVelocity` hops when on ground and within 4 m of its target; scratch-the-itch for wall climb without a full adherence physics mode.
- **Enderman teleport** — every 3 s of aggro the enderman offsets (−3, 3) × (−3, 3) in x/z. Simple, reads well, no pathfind stall.
- **Spawn table** distributes across the new pools: skeleton 20% / creeper 20% / spider 20% / enderman 10% / zombie 30% at night; pig / cow / sheep / chicken evenly by day.
- **Rendering** — `MobRenderer` colour table extended; every new kind gets its own hue so the debug view stays legible.

## Cut / deferred

- **Skeleton arrow projectiles** — instant-damage ranged attack is a placeholder; real MC launches an Arrow entity that tumbles through the world. Needs a projectile component system.
- **Breeding** (pig / cow / sheep / chicken) + **wolf taming** — both blocked on item-use-on-entity plumbing.
- **Behavior-tree library** — premature for 10 kinds; `tickMob` is still readable. Re-evaluate when we exceed ~20 behaviors or need composite behaviors (flee+look+call-for-help).
- **Enderman block pick-up** and **water damage** — character quirks that depend on the yet-to-exist block-entity system.

## Biggest surprise

Replacing `hostile: bool` with `behavior: string` turned out cleaner than adding flags like `neutralUntilHit` / `explodesOnContact` — each new behavior fits a single `switch` arm and non-overlapping data fields (`fuseSec`, `teleportCooldownSec`, `provoked`). The old code was already a switch-in-disguise; naming it made extension one arm per kind instead of a web of conditionals. Spider jump fell out of `jumpVelocity?: number` — 4 lines of code, no new system.

## What the next milestone should know

- **`MobWorld.damage()`** is the provocation channel — it flips `provoked` for neutrals and triggers death at zero. Any external damage source (arrow, lava, fall, player hit) must go through it to behave correctly.
- **Creeper fuse** lives in `fuseSec` and auto-decays if the target moves out of range; don't cheese it by jumping over a creeper (range check is 3D because it's `attackRangeSq`).
- **Spawn table** is weighted per-call; don't assume uniform distribution in tests. `ctx.rng` is injectable for deterministic tests.
- **No arrow entity yet.** Skeletons deal damage instantly at range — if M13 nether adds ghasts we'll need the projectile system first.
