# M13 — Nether (Retrospective)

## Shipped

- **11 new blocks**: netherrack, soul_sand, nether_brick, nether_quartz_ore, magma_block, obsidian, bedrock, portal, end_stone, end_portal_frame — the full nether palette plus enough end bricks to unblock M14 prep.
- **NetherGenerator** — independent chunk generator using `fbm3` at freq 1/18 with abs-threshold 0.22 for solid-vs-air, carving a 128-tall dimension with bedrock floor + ceiling, lava sea at y≤32, soul-sand veins near the sea, magma sprinkles, quartz ore scattering, and glowstone studded in the ceiling layer.
- **DimensionRegistry** — lightweight dimension index with scale-aware coordinate translation (`a.scale / b.scale`). Overworld (1) ↔ nether (8): 800 ↔ 100 blocks.
- **Portal frame detection** — `findPortalFrame(lookup, sx, sy, sz)` sweeps both axes × an 8-wide search for a 4h × 3w obsidian ring enclosing a 3h × 2w air interior. Returns the 6 inner cells for portal-block fill, or null.
- **4 nether mob defs**: ghast (huge flyer, 10 HP, 6 dmg, 48m range — no projectile yet), blaze (small flyer, 20 HP, 3 dmg, 16m), piglin (neutral humanoid, 16 HP, 3 dmg), wither_skeleton (tall undead, 20 HP, 5 dmg). All wired into the existing `behavior` switch so `MobWorld.tick` handles them unmodified.
- **Tests**: generator coverage (bedrock caps, lava + rack mass, sub-ceiling AIR, determinism), portal detection (valid x-axis, missing obsidian, non-air interior), dimension translation.

## Cut / deferred (to Post-M13)

- **Player portal travel** — frame detection works; the fade-to-black + coord-translate + swap dimension World mutation is main-loop-integration work.
- **Nether fortresses** — same cross-chunk structure blocker as M10 mineshafts / villages.
- **Ghast / blaze fireball projectiles** — blocked on projectile system (Post-M11).
- **Piglin gold bartering** — blocked on item-use-on-entity (Post-M11/M12).

## Biggest surprise

The `behavior: string` categorisation from M11 absorbed four new nether mob kinds with zero tick-loop changes — just new entries in `MOB_DEFS` and a render colour. Ghast as a "walking" 4m-box mob is wrong (ghasts fly), but it ships as-is until the projectile system lands. Dimension translation via `a.scale / b.scale` was a one-liner once the test got the direction right (I had it inverted initially — test-first caught it).

## What the next milestone should know

- **Portal-block state** (`webmc:portal`, light 11, non-solid, hardness -1) exists in the registry but has no "on step" travel behaviour yet. Add that alongside dimension-swap wiring.
- **Dimension scale** lives on `DimensionInfo.scale`; end is 1 (no translation), nether is 8. `DimensionRegistry.translate` already handles M14 end-portal math.
- **NetherGenerator has no trees / crimson forests / warped forests** — those are Post-M13 content. Generator uses the same Perlin seed offset (`seed ^ 0x1efe01`) so two worlds with the same seed produce the same nether.
- **Ghast behavior** is currently `'hostile'` ground-chase; swap to a flying behavior once an air-navigation mode exists.
