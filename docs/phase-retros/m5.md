## Shipped

- `src/persist/types.ts`: WorldMeta, ChunkBlob, PlayerState shapes + schema-version constant.
- `src/persist/db.ts`: `PersistDB` interface + `IndexedDBPersistDB` real impl. 4 object stores (worlds, chunks, player, meta), composite keyPath for chunks, cascade delete via cursor range.
- `src/persist/memory-db.ts`: `InMemoryPersistDB` pure-JS test double so DAL contract tests run in Node without jsdom/fake-indexeddb.
- `src/persist/chunk-codec.ts`: one-allocation binary encoder (`WEBC` magic, LE header, per-section palette+indices+optional light, CRC-32 trailer). Decoder reverses with full verification; rejects bad magic, length mismatch, and tampered CRC.
- `src/persist/ChunkStore.ts`: dirty-queue + batch flush + auto-flush timer. Wraps DAL+codec behind `markDirty(chunk, light?)` / `flush()` / `load(cx, cz)`.
- `ChunkLoader.setPopulate(asyncFn)`: loader can now run an async populate step (load from DB → fall back to generator). Generating-flag serializes async population so one chunk at a time goes through IDB.
- `main.ts`: boots the DB, get-or-creates default-world, restores player pose, wires persistent chunks + periodic/visibility/beforeunload flushes. HUD shows `save<pending>` counter.
- e2e `m5-persistence.spec.ts` clears IDB, walks, waits past save interval, reloads, asserts position restored within 2 m.

## Cut or deferred (to backlog.md)

- **Zstd compression (M5.3).** Raw bytes today. Typical chunk is ~2 KB so the un-compressed cost is manageable; wasm zstd buys ~3x shrink but adds 50 KB dep and a loader dance. Deferred.
- **World selector UI (M5.5).** Currently a single hard-coded `default-world` id. UI would add DOM modal with list/create/delete/rename. All the DAL pieces are in place; it's pure frontend glue.
- **.webmc zip export/import (M5.6).** Same story — the per-chunk codec is in place; needs `client-zip` + `fflate` + a world.json sidecar.
- **Schema migrations scaffold (M5.7).** Not needed until schemaVersion 2 ships. The version byte is already in the header; migration file convention is in the design note.
- **Quota strategy.** `navigator.storage.estimate` not checked; quota-exceeded today would silently drop writes. Backlog.

## Biggest surprise

Playwright's `page.reload()` keeps IndexedDB by default (as it should — it's a hard browser reload, not a fresh context). But concurrent test workers share the same origin, so IDB state leaks between specs unless each clears first. The M5 reload test now clears IDB at start via `indexedDB.databases()` + `deleteDatabase()`. If this e2e flakes in the future it's almost certainly that cleanup racing with a prior worker.

Second: `ChunkLoader` was synchronous. Adding the async populate path needed a one-at-a-time serialization (the `generating` flag) to prevent 24 concurrent IDB transactions from piling up when the player crosses into fresh territory. Trading throughput for back-pressure fairness; fine at 6-chunk radius, revisit when M3 view radius grows past 12.
